## 1. 新项目搭建

### 1.1 项目结构说明

RPA框架采用分离式架构设计：
- `rpa_framework/`: 基础框架，保持稳定，不经常修改
- `src/`: 新开发的机器人代码目录
- `config/`: 配置文件目录
- `data/`: 数据文件目录
- `docs/`: 文档目录

### 1.2 新项目创建步骤

#### 步骤1：创建Python项目
```bash
# 创建新项目目录
mkdir my_rpa_project
cd my_rpa_project

# 创建虚拟环境
python -m venv venv
venv\Scripts\activate  # Windows
# source venv/bin/activate  # Linux/Mac
```

#### 步骤2：解压RPA框架
将`rpa_framework.zip`解压到项目根目录，确保包含以下目录结构：
```
my_rpa_project/
├── rpa_framework/          # 基础框架
├── config/                 # 配置文件
├── data/                   # 数据文件
├── docs/                   # 文档
├── src/                    # 机器人源码
├── build.bat              # 打包脚本
├── make_spec.bat          # GUI打包配置
├── make_spec_cli.bat      # CLI打包配置
├── main.py                # GUI入口
├── main_cli.py            # CLI入口
└── requirements.txt       # 依赖包
```

#### 步骤3：安装依赖
```bash
# 安装基础依赖
pip install -r requirements.txt

# 安装Playwright浏览器
playwright install
```

#### 步骤4：验证安装
```bash
# 测试GUI模式
python main.py

# 测试CLI模式
python main_cli.py -h
```

### 1.3 开发环境配置

#### IDE配置（推荐PyCharm）
1. 设置项目解释器为虚拟环境
2. 配置代码风格为PEP8
3. 启用类型检查
4. 配置调试器

#### 开发工具推荐
- **IDE**: PyCharm Professional / VS Code
- **浏览器**: Chrome DevTools
- **调试工具**: Playwright Inspector
- **版本控制**: Git

## 2. 打包命令使用

### 2.1 打包脚本说明

#### build.bat - 主打包脚本
```bash
# 执行完整打包流程
build.bat
```

**打包流程**：
1. 清理旧的构建文件
2. 生成GUI版本spec文件
3. 生成CLI版本spec文件
4. 构建GUI版本
5. 构建CLI版本
6. 复制配置文件和资源

#### make_spec.bat - GUI版本配置
```bash
# 生成GUI版本spec文件
make_spec.bat
```

#### make_spec_cli.bat - CLI版本配置
```bash
# 生成CLI版本spec文件
make_spec_cli.bat
```

打包完成后，在`dist/`目录下生成：
```
dist/
├── RPA_GUI/              # GUI版本

└── RPA_CLI/              # CLI版本
    ├── RPA_CLI.exe       # CLI主程序
    ├── config/           # 配置文件
```

## 3. RPA框架使用指导

### 3.1 BasePw核心类

#### 3.1.1 基础用法
```python
from rpa_framework.core.base_pw import BasePw
from playwright.sync_api import sync_playwright

def main(**kwargs):
    with sync_playwright() as playwright:
        with BasePw(playwright, show_browser=True, record_video=True) as base_pw:
            # 初始化浏览器
            base_pw.init_browser()
            
            # 执行操作
            base_pw.page.goto("https://example.com")
            
            # 关闭浏览器（自动处理）
```

#### 3.1.2 主要接口

**浏览器初始化**
```python
# 初始化浏览器
base_pw.init_browser()

# 设置页面
base_pw.set_page(page)

# 获取主页面
main_page = base_pw.get_main_page()
```

**元素定位与操作**

所有定位方法都支持以下可选参数：
- `wait` (bool): 是否等待元素出现，默认True
- `exact` (bool): 是否精确匹配，默认False  
- `timeout` (int): 超时时间（毫秒），默认使用配置的超时时间
- `sleep` (int): 操作后等待时间（毫秒），默认0

```python
# 定位并填充
base_pw.locate_and_fill("用户名输入框", "admin", wait=True, timeout=10000)

# 定位并点击
base_pw.locate_and_click("登录按钮", sleep=1000)  # 点击后等待1秒

# 定位并选择
base_pw.locate_and_select("下拉框", "选项值", exact=True)

# 定位并勾选
base_pw.locate_and_check("复选框", wait=True)

# 定位并取消勾选
base_pw.locate_and_uncheck("复选框")

# 定位并填充（带按键）
base_pw.locate_and_fill("搜索框", "关键词", press_key="Enter")
```

**高级定位**
```python
# 通过定位器操作
locator = base_pw.locate_by_page("元素名称")
base_pw.locate_and_fill_by_locator("元素名称", locator, "值")

# 等待元素出现
locator = base_pw.locate_by_page("元素名称", wait=True, timeout=10000)
```

**截图和视频**
```python
# 截图
screenshot_path = base_pw.take_screenshot("截图名称", tag="errors")

# 获取视频路径
video_path = base_pw.get_video_path()
```

### 3.2 日志处理

#### 3.2.1 日志配置

**日志自动回显到GUI**：在GUI模式下，`logger.info()`、`logger.warning()`、`logger.error()` 等日志会自动回显到GUI界面的日志区域，无需额外配置。

```python

# 不同级别的日志（自动回显到GUI）
logger.debug("调试信息")  # 仅在调试模式下显示
logger.info("一般信息")   # 自动回显到GUI
logger.warning("警告信息") # 自动回显到GUI
logger.error("错误信息")   # 自动回显到GUI

# 带颜色的日志（GUI中会显示对应颜色）
logger.info("重要步骤", extra={'color': 'darkcyan'})
logger.info("操作完成", extra={'color': 'green'})
logger.warning("警告信息", extra={'color': 'orange'})
logger.error("错误信息", extra={'color': 'red'})
```

### 3.3 异常处理

#### 3.3.1 自定义异常
```python
from rpa_framework.utils.robot_exception import RobotsException

try:
    # 业务逻辑
    base_pw.locate_and_click("不存在的按钮")
except RobotsException as e:
    raise e 
except Exception as e:
    raise RobotsException(f"Robot执行出错: {str(e)}")
```

#### 3.3.2 异常处理最佳实践

**分层异常处理原则**：
- **底层函数**：捕获具体异常，转换为`RobotsException`后重新抛出
- **顶层函数**：统一处理`RobotsException`，框架已自动处理异常信息
```python
def execute_business_logic(base_pw):
    """底层函数 - 具体异常处理"""
    try:
        # 具体业务逻辑
        base_pw.locate_and_click("登录按钮")
    except RobotsException as e:
        raise e
    except Exception as e:
        # 底层直接抛出RobotsException
        raise RobotsException("点击登录按钮失败", e)
```

## 5. 数据库工具使用

### 5.1 功能说明

提供SQLite数据库操作，支持工单数据的增删改查、去重等功能

### 5.2 基本用法

```python
from rpa_framework.utils.db_util import DatabaseManager

# 初始化数据库管理器
db_manager = DatabaseManager("data/workorder.db")

# 初始化数据库（创建表结构）
db_manager.init_database()

# 查询已存在的工单号（最近10天）
existing_numbers = db_manager.get_existing_work_order_numbers(days_back=10)

# 插入工单数据
data = [
    ("WO001", "工单1", "2024-12-01", "处理中"),
    ("WO002", "工单2", "2024-12-01", "已完成")
]
fields = ["work_order_number", "title", "created_date", "status"]
inserted_count = db_manager.insert_workorders(data, fields)

# 保存数据（自动去重）
new_data = [
    ("WO003", "工单3", "2024-12-01", "新建"),
    ("WO004", "工单4", "2024-12-01", "新建")
]
saved_count = db_manager.save_workorders_with_deduplication(
    new_data, fields, existing_numbers
)
```

### 5.3 高级查询

```python
# 执行自定义查询
results = db_manager.execute_query(
    "SELECT * FROM work_orders WHERE status = ? AND created_date >= ?",
    ("处理中", "2024-12-01")
)

# 执行更新操作
updated_count = db_manager.execute_update(
    "UPDATE work_orders SET status = ? WHERE work_order_number = ?",
    ("已完成", "WO001")
)
```

## 6. Excel工具使用

### 6.1 功能说明

提供Excel文件的读写操作，支持多种数据格式和操作方式

### 6.2 基本用法

```python
from rpa_framework.utils.excel_utils import ExcelUtils

# 创建Excel工具实例
excel = ExcelUtils("data/input.xlsx")

# 读取Excel数据（字典格式）
records = excel.read_excel(
    sheet_name="Sheet1",
    header_row=0,  # 第一行作为表头
    na_fill=""     # 空值填充为空字符串
)

for record in records:
    print(f"行号: {record['__row__']}, 数据: {record}")

# 写入数据
data = [
    ["姓名", "年龄", "部门"],
    ["张三", 25, "技术部"],
    ["李四", 30, "销售部"]
]
excel.write_excel(data, sheet_name="员工信息")

# 追加一行数据
excel.write_row(["王五", 28, "人事部"], sheet_name="员工信息")

# 写入一列数据
excel.write_col(["A001", "A002", "A003"], col="D", start_row=2)
```

### 6.3 高级操作

```python
# 迭代读取Excel（大文件处理）
for row_num, row_data in excel.iter_excel(
    sheet_name="Sheet1",
    start_row=2,  # 从第2行开始
    columns="A:C"  # 只读取A到C列
):
    print(f"第{row_num}行: {row_data}")

# 读取指定单元格
cell_value = excel.read_cell(row=1, col="A", sheet_name="Sheet1")

# 获取最大行号
max_row = excel.get_max_row(sheet_name="Sheet1", col="A")

# 创建新工作表
excel.create_sheet("新工作表")

# 复制工作表
excel.copy_sheet("源工作表", "目标工作表")
```

### 6.4 注意事项

- 只支持`.xlsx`格式文件
- 使用完毕后会自动保存并关闭文件
- 支持中文路径和文件名

## 8. RPA_CLI.exe运行参数

### 8.1 基本参数

```bash
# 查看帮助
RPA_CLI.exe -h

# 运行指定机器人
RPA_CLI.exe -r robot_code

# 显示浏览器窗口
RPA_CLI.exe -r robot_code -b

# 录制视频
RPA_CLI.exe -r robot_code -v

# 调试模式
RPA_CLI.exe -r robot_code -d
```

### 8.2 参数详解

| 参数 | 长参数 | 说明 | 示例 |
|------|--------|------|------|
| `-r` | `--robot` | 要运行的robot代码 | `-r bank_account_collector` |
| `-f` | `--robot-file` | 自定义robot文件路径 | `-f "D:\my_robot.py"` |
| `-b` | `--show-browser` | 显示浏览器窗口 | `-b` |
| `-v` | `--record-video` | 录制屏幕视频 | `-v` |
| `-i` | `--input-file` | 输入文件路径 | `-i "D:\data.xlsx"` |

### 8.3 使用示例

#### 银行账户补采
```bash
# 显示浏览器 + 录屏
RPA_CLI.exe -b -v -r bank_account_collector -i "D:\data\银行账号补采.xlsx"

# 后台运行
RPA_CLI.exe -r bank_account_collector -i "D:\data\银行账号补采.xlsx"
```

#### 陕西监控
```bash
# 调试模式，单步执行
RPA_CLI.exe -d -b -r shanxi_jiankong -i "D:\data\陕西监控.xlsx"
```

#### 影刀订单采集
```bash
# 显示浏览器
RPA_CLI.exe -b -r yingdao_order_collector

# 后台运行 + 录屏
RPA_CLI.exe -v -r yingdao_order_collector
```

#### 自定义机器人
```bash
# 显示浏览器
RPA_CLI.exe -r custom -f "D:\test_robot.py" -b

# 后台运行 + 录屏
RPA_CLI.exe -r custom -f "D:\test_robot.py" -v

# 带输入文件
RPA_CLI.exe -r custom -f "D:\test_robot.py" -i "D:\input.xlsx" -b
```

## 9. 调度任务设置

### 9.1 Windows计划任务

#### 9.1.1 创建批处理文件

## 10. Playwright定位最佳实践

### 10.1 选择器优先级

#### 10.1.1 推荐顺序
1. **Role选择器** - 最稳定
2. **Text选择器** - 语义清晰
3. **ID选择器** - 唯一性好
4. **CSS选择器** - 灵活性强
5. **XPath选择器** - 复杂场景

#### 10.1.2 选择器示例
```python
# 推荐：ID选择器
"#username"
"#login-btn"

# 推荐：Role选择器
"role=button[name=登录]"
"role=textbox[name=用户名]"
"role=link[name=首页]"

# 推荐：Text选择器
"text=登录"
"text='用户管理'"
"text=/.*登录.*/"

# 推荐：CSS选择器
"button[type='submit']"
"input[name='username']"
".login-form button"

# 不推荐：XPath（除非必要）
"xpath=//button[contains(text(),'登录')]"
```

### 10.2 定位策略

#### 10.2.1 唯一性定位
```python
# 好的做法：确保唯一性
"#login-form button[type='submit']"  # 在登录表单中的提交按钮
"div.user-panel button:has-text('退出')"  # 用户面板中的退出按钮

# 避免：可能不唯一
"button"  # 页面可能有多个按钮
".btn"    # 可能有多个按钮类
```

#### 10.2.2 容错性定位
```python
# 好的做法：容错性强
"button:has-text('登录')"  # 包含"登录"文本的按钮
"input[placeholder*='用户名']"  # placeholder包含"用户名"的输入框

# 避免：过于精确
"button:has-text('请点击登录按钮')"  # 文本可能变化
```

#### 10.2.3 动态内容处理
```python
# 处理动态ID
"input[id*='username']"  # ID包含username的输入框

# 处理动态类名
"button[class*='btn']"  # 类名包含btn的按钮

# 处理动态文本
"button:has-text(/.*登录.*/)"  # 包含"登录"的按钮
```

### 10.3 等待策略

#### 10.3.1 显式等待
```python
# 等待元素出现
page.wait_for_selector("button:has-text('登录')", timeout=10000)

# 等待元素消失
page.wait_for_selector("button:has-text('登录')", state="hidden")

# 等待页面加载完成
page.wait_for_load_state("networkidle")
page.wait_for_load_state("domcontentloaded")
```

#### 10.3.2 隐式等待
```python
# 设置全局超时
page.set_default_timeout(30000)
page.set_default_navigation_timeout(30000)

# 在BasePw中已配置
base_pw.context.set_default_timeout(30000)
base_pw.context.set_default_navigation_timeout(30000)
```

## 11. 常见问题与解决方案

### 11.1 环境问题

#### 问题1：Playwright浏览器未安装
**症状**: `Browser not found` 错误
**解决方案**:
```bash
# 安装Playwright浏览器
playwright install

# 或者安装特定浏览器
playwright install chromium
playwright install firefox
playwright install webkit
```

#### 问题2：依赖包缺失
**症状**: `ModuleNotFoundError`
**解决方案**:
```bash
# 安装所有依赖
pip install -r requirements.txt

# 或者手动安装关键依赖
pip install playwright pandas openpyxl
```

### 11.2 运行问题

#### 问题3：元素定位失败
**症状**: `TimeoutError` 或元素找不到
**解决方案**:
```python
# 1. 增加等待时间
base_pw.locate_and_click("按钮", timeout=30000)

# 4. 截图调试
base_pw.take_screenshot("定位失败", tag="errors")
```

#### 问题4：页面加载超时
**症状**: `Navigation timeout` 错误
**解决方案**:
```python
# 1. 增加导航超时时间
page.set_default_navigation_timeout(60000)

# 2. 等待页面完全加载
page.wait_for_load_state("networkidle")
page.wait_for_load_state("domcontentloaded")

# 3. 检查网络连接
# 确保网络稳定，必要时使用代理
```

### 11.3 打包问题

#### 问题5：PyInstaller打包失败
**症状**: 打包过程中出错
**解决方案**:
```bash
# 1. 清理缓存
rmdir /s /q build
rmdir /s /q dist

# 2. 重新安装PyInstaller
pip uninstall pyinstaller
pip install pyinstaller
```

**症状**: 打包成功但运行时报错

```python
# 1. 检查隐藏导入

hiddenimports=[
```

### C. 机器人开发模板

```python
"""
机器人开发模板
"""
from rpa_framework.core.base_pw import BasePw
from rpa_framework.utils.log import logger
from playwright.sync_api import sync_playwright
from rpa_framework.utils.config import config
from rpa_framework.utils.robot_exception import RobotsException
import time
from typing import Dict, Any

def main(**kwargs):
    """主函数
    
    Args:
        **kwargs: 参数字典
            - show_browser (bool): 是否显示浏览器
            - record_video (bool): 是否录制视频
            - debug_mode (bool): 是否启用调试模式
            - input_file (str): 输入文件路径（可选）
    """
    try:
        logger.info("开始执行机器人")
        logger.debug(f'输入参数: {kwargs}')
        
        # 获取参数
        show_browser = kwargs.get("show_browser", False)
        record_video = kwargs.get("record_video", False)
        debug_mode = kwargs.get("debug_mode", False)
        input_file = kwargs.get("input_file", None)
        
        with sync_playwright() as playwright:
            with BasePw(playwright, show_browser, record_video) as base_pw:
                # 初始化浏览器
                base_pw.init_browser()
                
                # 步骤1: 访问页面
                logger.info("步骤1: 访问目标页面", extra={'color': 'darkcyan'})
                base_pw.page.goto("https://example.com")
                base_pw.page.wait_for_load_state('networkidle')
                
                if debug_mode:
                    input("按回车键继续...")
                
                # 步骤2: 执行操作
                logger.info("步骤2: 执行主要操作", extra={'color': 'darkcyan'})
                # 在这里添加具体的业务逻辑
                
                # 步骤3: 截图
                screenshot_path = base_pw.take_screenshot("操作完成", tag="screen")
                logger.info(f"截图已保存: {screenshot_path}")
                
                # 返回结果
                result = {
                    "success": True,
                    "data_file": None,
                    "video_file": base_pw.get_video_path(),
                    "screenshot_file": screenshot_path
                }
                
                logger.info("机器人执行完成", extra={'color': 'green'})
                return result
                
    except RobotsException as e:
        logger.error(f"机器人执行出错: {e.message}", 
                    exc_info=config.get_exc_info(), 
                    stack_info=config.get_stack_info())
        raise
    except Exception as e:
        logger.error(f"机器人执行出错: {str(e)}", 
                    exc_info=config.get_exc_info(), 
                    stack_info=config.get_stack_info())
        raise

if __name__ == "__main__":
    # 本地测试
    main(show_browser=True, record_video=False)
```
