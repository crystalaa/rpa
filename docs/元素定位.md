# 元素定位说明


## 一、CSS 选择器定位

### 基础 CSS 选择器

```python
# 通过标签名定位
page.locator("button")

# 类选择器（Class Selector）
page.locator(".submit-btn")

# ID 选择器（ID Selector）
page.locator("#username")

# 组合定位
page.locator("input.form-control.email")  # 同时有 form-control 和 email 类
```
其他常见类名组合写法
|场景|写法|说明
|------|-----|-----
|同时满足多个类（无空格）|.class1.class2|匹配同时有 class1 和 class2 的元素
|匹配其中一个类（逗号分割）|.class1, .class2|匹配有 class1 或 class2 的元素
|层级嵌套（空格分割）|.parent   .child|匹配 parent 下的 child 元素

### 属性选择器（Attribute Selector）

```python
# 精确匹配属性值
page.locator("[type='submit']")

# 包含某属性
page.locator("[disabled]")

# 属性值包含特定字符串（字符查找）
page.locator("[class*='error']")

# 属性值包含特定属性（word 独立单词）
page.locator("[class~='error']")

# 选择 lang 属性等于 en，或者以 en- 为开头的所有元素
page.locator("[lang|='en']")

# 属性值以特定字符串开头
page.locator("[href^='https']")

# 属性值以特定字符串结尾
page.locator("[src$='.png']")
```

### 关系选择器

```python
# 后代选择器
page.locator("div.container span")  # div 下的所有 span

# 直接子元素
page.locator("ul > li")  # ul 的直接子 li

# 相邻兄弟元素
page.locator("h1 + p")  # 紧接在 h1 后的 p

# 后续所有兄弟元素
page.locator("h2 ~ p")  # h2 后面的所有 p
```

### 伪类选择器

```python
# 第一个/最后一个子元素
page.locator("li:first-child")
page.locator("li:last-child")

# 第n个子元素
page.locator("tr:nth-child(2n+1)")  # 奇数行

# 匹配文本内容
page.locator("button:text('Submit')")  # Playwright 扩展语法

# 匹配可见元素
page.locator("input:visible")
```

## 二、XPath 定位

### 基础 XPath 表达式

```python
# 绝对路径
page.locator("xpath=/html/body/div/form/input")

# 相对路径
page.locator("xpath=//input")

# 通过属性定位
page.locator("xpath=//input[@id='username']")
page.locator("xpath=//*[@class='error']")

# 通过文本定位
page.locator("xpath=//button[text()='Submit']")
page.locator("xpath=//a[contains(text(),'Log')]")
```

### XPath 轴定位

```python
# 父节点
page.locator("xpath=//input[@id='username']/..")

# 子节点
page.locator("xpath=//div[@id='container']/*")

# 祖先节点
page.locator("xpath=//input[@id='username']/ancestor::form")

# 后代节点
page.locator("xpath=//div[@id='nav']/descendant::a")

# 后续兄弟节点
page.locator("xpath=//h2/following-sibling::p")

# 前面兄弟节点
page.locator("xpath=//h2/preceding-sibling::h1")
```

### XPath 函数

```python
# 包含特定文本
page.locator("xpath=//a[contains(@href, 'logout')]")

# 以...开头
page.locator("xpath=//input[starts-with(@id, 'user_')]")

# 逻辑运算
page.locator("xpath=//input[@type='text' and @required]")
page.locator("xpath=//button[text()='Save' or text()='Submit']")

# 位置索引
page.locator("xpath=(//table//tr)[2]")  # 第二个 tr
```

## 三、最佳实践与技巧

### 1. 优先使用 CSS 选择器

- 通常性能更好
- 语法更简洁
- 大多数场景下足够使用

### 2. 何时使用 XPath

- 需要根据文本内容定位时
- 需要复杂层级关系定位时
- CSS 无法满足的特殊定位需求

### 3. 定位策略建议

```python
# 1. 优先使用 Playwright 内置定位器
page.get_by_role("button", name="Submit")
page.get_by_label("Username")
page.get_by_placeholder("name@example.com")
page.get_by_text("Welcome back")

# 2. 使用 CSS 选择器
page.locator("button.primary")

# 3. 最后考虑 XPath
page.locator("xpath=//button[contains(@class, 'primary')]")
```

### 4. 调试定位表达式

```python
# 检查匹配元素数量
print(page.locator("xpath=//button").count())

# 高亮显示匹配元素
page.locator("button").highlight()
```

### 5. 等待元素出现

```python
# 等待元素可见
page.locator("#loading").wait_for(state="hidden")

# 等待元素可点击
page.locator("button").click(timeout=10000)
```

## 四、等价Locator

### 1、get_by_text() (文本内容)

``` python
# 等效写法
element = page.get_by_text("Submit")  # 推荐
element = page.locator("text=Submit")  # 等价
element = page.locator("text=/submit/i")  # 正则匹配（不区分大小写）
```

示例：点击包含 "Login" 文本的按钮

``` python
page.get_by_text("Login").click()
# 等效
page.locator("text=Login").click()
```

### 2、get_by_role() (ARIA 角色)

用途：通过 ARIA 角色（如 button、heading）定位

``` python
# 等效写法
button = page.get_by_role("button", name="Submit")  # 推荐
button = page.locator("role=button[name='Submit']")  # 等价
```

示例：定位一个名为 "Search" 的按钮
``` python
page.get_by_role("button", name="Search").click()
# 等效
page.locator("role=button[name='Search']").click()
```

### 3、get_by_label() (关联标签文本)

用途：通过 <label> 关联的表单元素定位

```python
# 等效写法
input = page.get_by_label("Username")  # 推荐
input = page.locator("label:has-text('Username') >> input")  # 近似等价
```

示例：填写标签为 "Email" 的输入框
``` python
page.get_by_label("Email").fill("test@example.com")

# 近似等效

page.locator("label:has-text('Email') >> input").fill("test@example.com")
```
### 4、get_by_placeholder() (占位文本)
用途：通过输入框的 placeholder 属性定位

``` python

# 等效写法

input = page.get_by_placeholder("Enter your name")  # 推荐
input = page.locator("[placeholder='Enter your name']")  # 等价
```

示例：填写占位符为 "Password" 的输入框
``` python
page.get_by_placeholder("Password").fill("123456")

# 等效

page.locator("[placeholder='Password']").fill("123456")
``` 
### 5、get_by_alt_text() (图片替代文本)
用途：通过 <img> 的 alt 属性定位

``` python

# 等效写法

image = page.get_by_alt_text("Company Logo")  # 推荐
image = page.locator("img[alt='Company Logo']")  # 等价
``` 
示例：点击 alt 为 "Banner" 的图片

``` python
page.get_by_alt_text("Banner").click()

# 等效

page.locator("img[alt='Banner']").click()
```
### 6、get_by_title() (title 属性)
用途：通过 title 属性定位

``` python

# 等效写法

element = page.get_by_title("Tooltip text")  # 推荐
element = page.locator("[title='Tooltip text']")  # 等价
```

示例：定位 title 为 "Close" 的元素
``` python
page.get_by_title("Close").click()

# 等效

page.locator("[title='Close']").click()
```
### 7、get_by_test_id() (自定义测试 ID)
用途：通过 data-testid 属性定位（推荐用于测试）

``` python

# 等效写法

button = page.get_by_test_id("submit-button")  # 推荐
button = page.locator("[data-testid='submit-button']")  # 等价
```
示例：点击测试 ID 为 "login-btn" 的按钮

``` python
page.get_by_test_id("login-btn").click()

# 等效

page.locator("[data-testid='login-btn']").click()
``` 
### 8、get_by_locator() 链式调用
用途：组合多个定位条件

``` python

# 定位表单中特定的提交按钮

form = page.locator("form.login-form")
submit = form.get_by_role("button", name="Submit")

# 等效链式写法

submit = page.locator("form.login-form >> role=button[name='Submit']")
``` 
### 总结对比表
|get_by_* 方法 |   等效 locator() 写法 |   适用场景
|------------------------|-----------------------------|-------------------
|get_by_text("Submit")  |  locator("text=Submit")  |  按可见文本定位
|get_by_role("button") |   locator("role=button")  |  按 ARIA 角色定位
|get_by_label("Email") |   locator("label:has-text('Email') >> input") |   按关联标签定位表单元素
|get_by_placeholder()  |  locator("[placeholder='...']") |   按输入框占位符定位
|get_by_alt_text()  |  locator("img[alt='...']")  |  按图片替代文本定位
|get_by_title()   | locator("[title='...']")  |  按 title 属性定位
|get_by_test_id() |   locator("[data-testid='...']") |   按专用测试 ID 定位（最稳定）



## 五、常见问题解决

### 1. 元素定位不到

- 检查 iframe (需要使用 `frame.locator()`)
- 检查动态生成的 ID/类名
- 添加等待时间 `page.wait_for_selector()`

### 2. 定位到多个元素

```python
# 获取第一个匹配元素
page.locator("button").first.click()

# 获取最后一个
page.locator("button").last.click()

# 按索引获取
page.locator("button").nth(2).click()
```

### 3. 动态内容定位

```python
# 使用正则表达式

# 使用 XPath 函数

```

通过掌握这些定位技巧，你可以高效准确地定位页面上的各种元素，为自动化测试打下坚实基础。

在 CSS 属性选择器中，`*=` 表示 **"包含匹配"**（子字符串匹配）。具体到你的代码：

```python
page.locator("[style*='width: 100%']")
```

这里的 `*=` 表示：选择 **`style` 属性中包含子字符串 `'width: 100%'`** 的元素，无论该字符串出现在 `style` 属性的哪个位置。

---

### **详细解释**

#### 1. `*=` 的作用

- 匹配属性值中 **任意位置** 出现的指定子字符串。
- 类似字符串的 `contains` 操作。

#### 2. 在你的代码中的含义

```python
has=page.locator("[style*='width: 100%']")
```

表示：等待 `.progress-bar` 元素内部存在 **某个子元素**，且该子元素的 `style` 属性中包含 `width: 100%`（即进度条已满）。

---

### **对比其他 CSS 属性匹配运算符**

| **运算符** | **含义**       | **示例**                   | **匹配示例**                     |
| ------- | ------------ | ------------------------ | ---------------------------- |
| `=`     | 完全等于         | `[width="100"]`          | `width="100"`                |
| `*=`    | 包含子字符串       | `[style*="width: 100%"]` | `style="...width: 100%;..."` |
| `^=`    | 以子字符串开头      | `[href^="https"]`        | `href="https://example.com"` |
| `$=`    | 以子字符串结尾      | `[src$=".png"]`          | `src="image.png"`            |
| `~=`    | 包含完整单词（空格分隔） | `[class~="active"]`      | `class="button active"`      |
| `\|=`   | 以单词开头（连字符分隔） | `[lang\|="en"]`          | `lang="en-US"`               |

---

### **实际应用场景**

#### 1. 进度条检测

```html
<!-- 目标元素 -->
<div class="progress-bar">
  <div style="width: 100%; background: green;"></div>
</div>
```

你的代码能正确匹配到 `style` 属性包含 `width: 100%` 的子元素。

#### 2. 更健壮的写法

如果进度值可能动态变化（如 `width: 99.9%`），建议改用正则表达式：

```python
import re
page.locator(".progress-bar").wait_for(
    has=page.locator("[style]").filter(
        lambda el: re.search(r"width:\s*100%", el.get_attribute("style"))
    )
)
```

---

### **为什么不用更简单的选择器？**

- 直接选 `[style="width: 100%"]` 可能失败，因为 `style` 属性通常包含多个 CSS 规则：
  
  ```html
  <div style="height: 20px; width: 100%; color: red;"></div>
  ```
  
  - `*=` 可以匹配这种复杂情况。

---

### **总结**

- `*=` 是 **"包含匹配"**，适合匹配属性中的部分值。
- 在进度条检测中，它能忽略 `style` 属性的其他内容，专注查找 `width: 100%`。
- 对于动态值或更复杂匹配，建议结合正则表达式。

在 Playwright 中，使用 `get_attribute()` 结合 `wait_for` 确实可以实现类似功能，但你的示例中使用 `[style*='width: 100%']` 这种 CSS 属性选择器有以下几个 **显著优势**：

---

### **1. 性能更高（原生浏览器引擎支持）**

- **CSS 选择器**：浏览器原生支持，直接通过 DOM 查询引擎匹配，无需额外 JavaScript 交互。
- **`get_attribute()`**：需要执行额外的 JavaScript 调用，并通过 Playwright 序列化数据，效率较低。

**对比代码**：

```python
# 高效写法（CSS 选择器）
page.locator(".progress-bar").wait_for(
    has=page.locator("[style*='width: 100%']")
)

# 低效写法（get_attribute）
def wait_for_100percent(locator, timeout=30_000):
    start = time.time()
    while True:
        if "width: 100%" in locator.get_attribute("style", timeout=timeout):
            return
        if time.time() - start > timeout:
            raise TimeoutError()
        time.sleep(0.5)

wait_for_100percent(page.locator(".progress-bar div"))
```

---

### **2. 代码更简洁**

- **CSS 选择器**：一行完成定位和条件判断。
- **`get_attribute()`**：需要手动实现轮询逻辑（如上例），代码冗余。

---

### **3. 内置等待重试机制**

- `locator.wait_for()` 已内置 **自动重试和超时处理**，而手动用 `get_attribute()` 需要自行实现重试逻辑。

---

### **4. 复合条件支持**

CSS 选择器可轻松组合其他条件（如同时匹配多个属性）：

```python
# 匹配宽度100%且背景为绿色的元素
page.locator("[style*='width: 100%'][style*='background: green']")
```

而 `get_attribute()` 需要多次调用并合并判断。

---

### **何时该用 `get_attribute()`？**

#### **场景 1：动态计算属性**

当属性值需要通过 JavaScript 动态计算时：

```python
opacity = page.locator("#fade-element").get_attribute("data-opacity")
```

#### **场景 2：非标准属性**

CSS 选择器无法匹配自定义属性时：

```python
status = page.locator("#item").get_attribute("data-custom-status")
```

#### **场景 3：精确格式控制**

需要严格校验属性值格式时：

```python
# 检查 style 是否精确包含 width:100%（无空格）
style = page.locator(".progress-bar").get_attribute("style")
assert "width:100%" in style  # 非 width: 100%
```

---

### **最佳实践总结**

| **场景**              | **推荐方案**                  | **理由**            |
| ------------------- | ------------------------- | ----------------- |
| 简单属性包含匹配（如 `style`） | CSS 选择器（`*=`）             | 高性能、代码简洁、内置等待     |
| 动态/复杂属性逻辑           | `get_attribute()` + 自定义判断 | 灵活处理非标属性或复杂条件     |
| 需要精确控制匹配格式          | `get_attribute()` + 正则表达式 | CSS 选择器无法实现精细文本匹配 |

---

### **改进你的进度条检测**

如果担心 `width: 99.9%` 这类近似值，可以 **结合两种方法**：

```python
# 先用 CSS 选择器快速定位近似值，再用 get_attribute 精确校验
progress = page.locator("[style*='width: ']").filter(
    lambda el: float(el.get_attribute("style").split("width:")[1].split("%")[0].strip()) >= 99.9
)
progress.wait_for()
```

根据实际需求选择最合适的工具，才能写出高效稳定的自动化脚本！
